Nhúng tính năng quét mặt
vào bất kỳ trang nào

Chỉ cần 3 dòng: import 2 file JS, tạo div, gọi SafeBus.init()

🔧 Cách nhúng vào dự án của nhóm bạn
<!-- Bước 1: Import thư viện (chỉ làm 1 lần) -->
<script src="./face-api.min.js"></script>
<script src="./safebus-sdk.js"></script>

<!-- Bước 2: Tạo container ở bất kỳ đâu trong trang -->
<div id="face-scan"></div>

<!-- Bước 3: Gọi 1 dòng lệnh -->
<script>
  SafeBus.init('face-scan', {
    busId:         'BUS-01',
    mode:          'checkin',   // hoặc 'register'
    modelsPath:    './models',

    // Callback khi học sinh quét thành công → móc vào backend của nhóm
    onScanSuccess: function(student, event) {
      console.log(student.full_name, event); // "Nguyễn An", "boarded"
      // fetch('/api/attendance', { method: 'POST', body: JSON.stringify({...}) })
    },

    // Callback khi có cảnh báo → hiện popup của hệ thống nhóm
    onAlert: function(alert) {
      if (alert.severity === 'critical') console.error(alert.message);
    }
  });
</script>

SDK Reference

API tham khảo

🚀
SafeBus.init(id, opts)
Khởi tạo widget vào container. Tự bật camera, tải model AI. Hỗ trợ mode checkin và register.
🗑
SafeBus.destroy(id)
Tắt camera, dọn dẹp DOM. Gọi khi chuyển trang hoặc không cần widget nữa.
🎯
onScanSuccess(student, event)
Callback khi quét mặt thành công. Nhận student (id, name) và event ('boarded'/'alighted').
🚨
onAlert(alert)
Callback khi có cảnh báo. Nhận alert.severity ('critical'/'warning') và alert.message.
📤
SafeBus.exportData()
Xuất toàn bộ dữ liệu học sinh + phân công xe ra file JSON. Dùng để backup hoặc import vào backend.
⚙️
SafeBus.engine.*
Truy cập trực tiếp các hàm engine: getStudentRegistry(), getRoster(busId), findBestMatch()...
